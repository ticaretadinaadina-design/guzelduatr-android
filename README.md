# Güzel Duatr - Android (Jetpack Compose)

Bu repo, dua, zikir ve namaz vakitleri gösteren örnek bir Android uygulamasıdır. Kotlin, Jetpack Compose, Hilt ve Retrofit kullanılarak hazırlanmıştır.

Özellikler:
- Ana Sayfa: Günün duası, hadis, Kur'an ayeti kartları
- Zikirler: Hazır zikirler ve sayaç (rememberSaveable ile temel koruma)
- Namaz Vakitleri: Aladhan API entegrasyonu ile şehir bazlı vakit çekme

Hızlı başlatma:
1. Android Studio'da projeyi açın.
2. Gradle senkronizasyonunu bekleyin.
3. Uygulamayı bir cihazda çalıştırın.

Not: Bu iskelet, örnek amaçlıdır. Daha sağlam persist ve hata yönetimi için Room/DataStore ve ek testler eklenmelidir.
